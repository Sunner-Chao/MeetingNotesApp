# 通用会议纪要

> 适用场景：行政会议、部门例会、经营讨论、头脑风暴、杂谈、讲座沙龙、专题交流及其他不需要专用项目或论坛结构的会议。
>
> 本模板采用智能适配结构。先理解原始内容属于哪种会议，再决定章节、表格和篇幅；不得为了填满固定模板而制造空章节。

## 智能适配规则（仅供生成，不写入最终纪要）

- **行政会议/部门例会**：突出决定、责任人、开始时间、检查时间、截止时间和下次汇报节点。
- **头脑风暴/创意讨论**：保留创意池、观点聚类、少数意见、关键假设和待验证方向，不把灵感写成正式立项。
- **杂谈/开放交流**：按话题脉络整理有价值的观点、案例和疑问；没有明确任务时不强行生成行动项。
- **讲座/沙龙**：区分主持人、主讲人和提问者，按知识主题、案例、问答和启发组织内容。
- **经营或专题讨论**：突出问题、证据、方案比较、决定、风险与后续动作。
- 混合型会议可以组合上述结构，并按实际内容增删、合并或重排章节。

## 输出约束

- “会议信息”和“核心摘要”为基础章节，其余章节可依据内容增删、合并、改名和重排。
- 先判断会议子类型，再选择最合适的表达结构；最终正文不要展示“智能适配规则”或解释选择过程。
- 讨论建议、投票倾向、灵感和待验证设想不得写成已经批准的决定。
- 负责人、时间、数字、制度、预算和验收标准未提及时写“待确认”或省略对应字段，不得编造。
- 行动项只在原始记录确有行动承诺时生成；杂谈、讲座和开放交流不得强行制造任务。
- 保留有价值的分歧、少数观点、案例和原话；无法确认说话人时写“发言人待确认”。
- 图片只描述可见事实，并与会议文字相互印证；无法确认时写“待确认”。
