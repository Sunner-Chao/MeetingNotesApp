# 自定义会议纪要

> 按需组合模块，可在录音页拖拽编排顺序与启停。

## 模板组合说明（仅用于生成）

以下模块按既定顺序可选使用。仅保留转写内容能够支撑的模块；没有对应事实、讨论或结论的模块直接省略，不得补造内容。这是未编排时的默认顺序；用户在录音页拖拽保存后，将按用户编排的顺序与启用范围生成。

## 2. 核心摘要

用简洁文字概括本次讨论的背景、重点与结果。

## 3. 议题与讨论

按议题记录关键事实、主要观点、依据与分歧。

## 4. 决策与共识

仅记录已经明确确认的决定、共识与适用范围。

## 5. 观点与问题

保留需要进一步讨论的观点、问题和待确认事项。
