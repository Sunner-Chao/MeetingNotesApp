# 录音暂停纪要与实际 STT 路由同步

日期：2026-08-25

## 变更目标

- 暂停不是结束：保留同一录音会话、累计时长、实时文本和 WAV 文件，用户可立即生成已有内容的纪要。
- 录音页的本地/云端控件显示当前真正接管实时转写的路由；用户保存的引擎偏好只作为下一次启动和路由不可用时的默认值。
- 暂停后的本地采集线程不再写入 WAV、不再向流式 STT 发送 PCM。

## 状态规则

`RecordingSessionState.isPaused` 由 `RecordingSessionController.pause()` 设置。控制器调用 `AudioRecorder.pause()` 停止原生 `AudioRecord`，冻结计时；继续时重新启动同一实例并从累计时长恢复。采集循环对暂停竞态下已返回的尾帧做丢弃保护，避免暂停后多写一帧。

`RecordingViewModel` 使用 `effectiveSttEngineType()` 映射路由：本地连接/活跃/恢复显示 Faster-Whisper，云端连接/切换/活跃/兜底接管显示腾讯云；`IDLE` 和不可用状态回退到保存的偏好。云端兜底不会覆盖用户偏好，因此下一次录音仍按用户选择启动。

有实时文本时立即将 `hasRecording` 置为真。暂停状态下只要已有文本且没有转写或纪要任务，右下角“生成纪要”启用；点击后收尾当前暂停会话、保存 WAV 与文本并排队纪要。
