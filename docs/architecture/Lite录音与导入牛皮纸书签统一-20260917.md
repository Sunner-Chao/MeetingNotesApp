# Lite 录音与导入牛皮纸书签统一

## 目标

- 实时转录与“顷刻成稿”使用同一牛皮纸主体和书签导航。
- 书签收起时完整露出竖排白字，根部藏在纸张下方；展开时只让当前书签抽出。
- 删除固定宽度、带投影的整条透明书签轨道，避免右侧出现无意义的长矩形区域。

## 实现

- `RecorderNotebookSurface` 统一 Lite 两个页面的纸张、书签、模板选择和自定义工作流。
- 纸张固定从书签右侧开始，书签使用独立层叠；收起书签置于纸张下层，展开书签置于纸张上层。
- 书签使用模板短名（如“推演会”“洽谈会”）竖排展示，选中态保留白色标记线。
- 导入页沿用实时页的顶部间距、背景、系统栏和纸张内边距；导入、手动输入和文本编辑均嵌入纸张。
- 模型切换和导入操作在窄屏/大字体下按可用空间换行，保持文字和控件可读。
