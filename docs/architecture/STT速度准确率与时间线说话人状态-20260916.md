# STT 速度、准确率与时间线展示状态

日期：2026-09-16

## 当前链路

- 本地：V100 FunASR Paraformer Large 在线模型负责实时预览，离线模型负责结束后的文件/段落整理。
- 云端：腾讯云由业务 STT 服务统一代理，实时与文件入口使用现有标准/精度策略。
- 选择与兜底：录音页选择本地或云端；本地流式连接失败时沿用既有云端接管逻辑。

## 速度与准确率边界

已有同一条 V100 公网回放样本：握手约 393 ms，首个实时片段约 1.07 s，模型推理中位约 86 ms，交付延迟 P50/P95 约 119/262 ms。V100 主机回环样本首片段约 0.99–1.01 s，交付约 96–105 ms。它们是链路样本，不是手机网络承诺。

目前没有使用同一音频、同一文本标注、同一噪声/口音分组计算本地与腾讯的 CER/WER，因此不写准确率百分比。准确率应通过带人工真值的对照集评估，不能用模型名称推断。

## 说话人分离

- V100 已部署 sherpa-onnx 分离模型，健康接口确认模型存在并已加载。
- V100 服务会在实时滚动窗口尝试本地分离，也会在停止时用离线音频重新对齐；但短句、重叠发言和网络重连仍可能改变匿名编号。
- 腾讯链路已解析 `speaker_id`、起止时间及分离元数据；是否有稳定标签取决于当前腾讯产品与账号配置，不能把“字段支持”当成质量保证。
- “说话人 1/2”是本场录音内的匿名编号，不是识别真实姓名。

## 时间段展示

录音页现在保留带起止时间的片段，优先使用服务端真实时间；没有逐句时间时，使用已处理音频位置作为段落锚点，不按文字长度伪造时间。已确认段落用青色左线，当前可修订段落用弱化线，形式对应参考图；说话人字段存在时在时间下显示“说话人 N”。实时预览仍直接更新当前段落，不等待最终文件转写或报告生成。

最终消息的片段也进入同一条 Android 管线，暂停、重连、切换引擎和重新进入会议时保持已有时间线。
