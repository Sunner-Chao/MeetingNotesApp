# 开源组件采用记录

## 采用原则

1. 业务闭环与交互可以对标，品牌、文案、图片和受限源码不得复制。
2. MIT、Apache-2.0 等宽松许可证项目仍需逐文件核验版权声明和额外条款。
3. GPL、AGPL 或未提供许可证的项目仅用于功能研究和黑盒行为验证。
4. 智悟本继续使用现有 FastAPI、Android Compose、Room 与离线同步架构，不因参考项目引入第二套后端。
5. 路径、接口、凭证、端口和功能开关必须动态配置，禁止写入业务源码。

## 待采用模板

后续实际引入第三方代码或素材时，必须补全：

- 仓库与作者
- 精确 commit SHA
- 许可证与额外条款
- 引入文件和依赖
- 修改内容
- 使用模块
- 素材来源与授权
- 升级和移除策略
