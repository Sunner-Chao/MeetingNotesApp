# 图片数量不限与插图管理（2026-08-22）

## 结论

- Android `MeetingAttachmentStore` 不设置图片数量上限，导入流程按用户选择的资源逐张持久化。
- Server Agent 的 `AGENT_MAX_IMAGES=0` 表示不限制图片数量；该值继续作为默认配置。
- 云端请求仍保留字节级保护：单张图片默认不超过 `12MB`，单次请求图片总大小默认不超过 `32MB`。这两个限制用于保护网络和推理资源，不是图片张数上限。
- 报告页原先达到 6 张后隐藏新增入口，已移除该条件；6 格仅是首屏预览布局，完整图片仍可继续追加并在图库中查看。

## 插图管理

- 录音页右上角菜单提供“管理插图”入口。
- 管理面板显示已添加数量，并支持拍照、相册批量导入、逐张删除。
- 提供“清空插图”操作，执行前二次确认；只删除图片，不影响录音、标记和转写文字。
- 图片预览保留插图标记样式，便于后续报告排版定位。

## 顷刻成稿导入与音频入口

- “应用导入”更名为“其他应用打开”。微信、飞书、QQ条目使用 Android `OpenDocument` 文件浏览器，不再只是启动对应应用；选择后按 MIME 类型和扩展名自动进入文本导入或音频转写。
- 顷刻成稿底部移除语音、生成、导入三枚切换/动作控件，生成纪要保留在顶部动作图标。
- 录音右上角不再放保存/分享音频菜单；自动保存的录音在页面内显示分享图标。

## 发布

- Android 版本：`1.2.39`（versionCode `10239`）。
- 发布说明：图片不再设置固定数量上限；录音页新增插图管理和录音分享入口；顷刻成稿支持从微信、飞书、QQ文件浏览导入，并精简底部操作。
- 发布必须使用固定签名 `release` APK，并通过 `server/deploy-remote.ps1 -WithBackend -AndroidApk` 原子更新 OTA 清单。
