# 录音页 V100 本地与云端切换

日期：2026-09-16

## 行为与顺序

保留现有 Lite 牛皮纸、书签和录音布局，在实时转录卡片右上角启用本地/云端分段选择。Lite 的临时限制已解除，同时保留构建参数 `meetingnotesLiteLocalSttEnabled=false` 作为部署开关。

- 进入页面时异步检查本地 `/ready`，不阻塞麦克风；“检测”按钮可再次检查。
- 检测只表示 V100 模型就绪，不代表账户鉴权或流式转录已经成功。WebSocket 返回会话确认后才展示连接已就绪。
- 选择本地时先检查模型就绪；失败保留当前引擎和文字。通过后，未录音则保存选择，录音中则保留已有文字、切换 WebSocket。
- 选择云端直接使用腾讯云入口，不绕经本地模型。
- 本地运行失败沿用快速恢复与云端接管；初始连接超时也进入云端兜底。手动切回本地清除旧接管标记，允许下一次故障再次兜底。
- 暂停中切换保持暂停；恢复后向新引擎上传。引擎切换不重启麦克风，录音文件和已有转写保留。
- 引擎选择写入应用设置和会议记录。页面展示以实际连接路由为准；断开后可点击当前引擎重试。

## 实现边界

底层 `FASTER_WHISPER` 枚举名称保留用于历史数据兼容，显示名称和默认模型已改为 V100 FunASR Paraformer。服务设置不再提供已停用的 Whisper 模型菜单。生产服务器选择在线/离线模型，手机只选择本地或腾讯云。

模型检测核验 JSON 中 `ready=true` 及 `engine=funasr-paraformer`，总超时 5 秒；不使用管理员页面。账户鉴权保持原有隔离逻辑。

开发构建配置已改为现有 V100 公网中继，避免继续访问旧 Windows 本机服务；实际部署地址保存在忽略的本地配置中，无凭据进入代码或笔记。

## 验证

代码回归覆盖模型就绪响应校验、失败后同地址重连、暂停时跨服务切换不上传 PCM、恢复后继续上传、说话人参数保留及切换中禁止重复录音操作。Kotlin 编译、353 项 JVM 单测和 lintDebug 全部通过。

用户明确要求设备验收自行完成：本轮不安装 APK，不进行真机或模拟器交互验收，不发布 OTA。

在该要求前完成的公网协议回放：10 秒合成音频，22 次实时输出，握手约 393 ms，首片段约 1.07 秒，交付延迟 P50/P95 约 119/262 ms，暂停/继续成功、无协议错误；停止排空约 4.27 秒。这是单次服务器链路验证，不等同手机网络或多人识别验收。

## 人工验收重点

1. 本地/云端切换后选中态、状态文案与实际转写一致。
2. 暂停时切换、返回再进入，仍保持选择和暂停状态。
3. 本地不可用时当前录音继续保存，云端接管有明确提示。
4. 本地检测失败不清空已转写文字；故障解除后可重新检测并切换。
